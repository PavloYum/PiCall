# Архитектура MVP

PiCall — телефония только между участниками приложения. Публичным адресом
участника служит неизменяемый PiCall ID формата `PC-XXXX-XXXX`. Отображаемое имя
можно менять и оно не уникально. Сервер создаёт ID криптографически случайно,
проверяет уникальность в базе и никогда не использует ID как пароль.

```text
Android PiCall
  |-- HTTPS: вход, контакты, TURN credentials
  |-- WebSocket: offer/answer/ICE, состояние звонка
  |-- WebRTC audio --------------------+
                                       |
API + signaling                  coturn на Pi 5
  |-- пользователи                |-- STUN/TURN :443
  |-- звонки                      `-- relay UDP 49152-65535
  `-- push через FCM
```

Signaling управляет звонком, но не передаёт аудио. Аудио идёт напрямую между
устройствами или через coturn, если прямое соединение невозможно.

SIP/PSTN и звонки на обычные телефонные номера не входят в основной продукт.
